# Casa Textil — Prototipo de ecommerce

Prototipo responsive para la preentrega del trabajo práctico de Marketing Digital e Ecommerce (UTN).

## Ver el sitio

Abrí `index.html` en un navegador, o publicá este repositorio usando GitHub Pages.

## Publicar con GitHub Pages

1. Crear un repositorio público en GitHub, por ejemplo `casa-textil`.
2. Subir `index.html` a la raíz del repositorio desde **Add file > Upload files**.
3. Ir a **Settings > Pages**.
4. En **Build and deployment**, elegir **Deploy from a branch**.
5. Seleccionar la rama **main** y la carpeta **/(root)**. Guardar.
6. Esperar a que GitHub indique que el sitio está publicado. En general, la URL es `https://TU-USUARIO.github.io/casa-textil/`.

**Importante:** Este es un prototipo académico. Las compras, los medios de pago, los precios y los costos de envío son demostrativos; no se procesan pagos ni pedidos reales.
